# Robu.in component and fabrication references

These links are references for the Pocket Gamebox build; they are not a confirmation that the listings are the exact purchased parts. Check current price, stock, connector pinout, and dimensions before ordering.

- **Raspberry Pi Pico (RP2040):** [Robu.in product page](https://robu.in/product/raspberry-pi-pico/)
- **2.4-inch 240×320 SPI LCD, ILI9341:** [Robu.in product page](https://robu.in/product/2-4-inch-spi-interface-240x320-touch-screen-tft-display-module/)
- **Custom PCB fabrication:** [Robu.in PCB manufacturing service](https://robu.in/product/online-pcb-manufacturing-service/)

**LCD compatibility note:** the Robu.in LCD listing describes a 10-pin ILI9341 module, while this project's schematic and firmware documentation currently specify an 8-pin display connection. Treat the LCD link as a controller/resolution reference only; verify the exact module and pinout against the PCB before buying or connecting it.
